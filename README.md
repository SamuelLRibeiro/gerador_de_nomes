# Gerador de Nomes de NPC

Um gerador de nomes de NPCs para RPG de mesa, criado para facilitar a vida de Dungeon Masters.  
Gera nomes masculinos e femininos combinando **primeiros nomes e sobrenomes** de forma aleatória, permitindo criar personagens únicos rapidamente.

---

## Funcionalidades

- Geração de nomes masculinos e femininos.
- Combinação de primeiro nome e sobrenome.
- Pode ser facilmente integrado em planilhas ou outros programas.
- Evita nomes repetidos (quando implementado com armazenamento).

---

## Como usar

1. Abra o programa Python.
2. Escolha o gênero do NPC: `masculino` ou `feminino`.
3. O programa gera um nome aleatório e mostra na tela.
4. Pode repetir quantas vezes quiser para gerar novos NPCs.
